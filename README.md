# TouchPad

Turn your Android tablet into a Mac graphics tablet, just like an iPad.

## 1. Intro

TouchPad 是一套轻量级、跨平台的数位板解决方案。它允许用户将 Android 平板电脑作为无线绘图板或触控板使用，实时控制 macOS 设备的光标。

## 2. 技术概要

### 2.1 系统架构

系统采用 **Client-Server** 架构，基于 TCP/IP 协议栈通信。

* **Server (macOS)**: 后台驻留程序，监听 TCP 端口 `9527` 接收指令。通过 `CoreGraphics` 事件 API 模拟系统级鼠标事件。**应用已内置 ADB 工具**，自动处理连接隧道。
* **Client (Android)**: 前台应用，捕捉 `MotionEvent` 触摸事件，计算坐标并封装为数据包发送。

### 2.2 通信协议

应用层采用基于文本的行协议，以换行符 `\n` 为分隔符。

* **指令格式**: `<ACTION>,<TOOL>,<X>,<Y>`
  * `ACTION`: MOVE / DOWN / UP / HOVER
  * `TOOL`: STYLUS / FINGER
* **控制指令**:
  * `IDENT,<NAME>`: 设备身份声明。
  * `CMD_LOCK` / `CMD_UNLOCK`: 远程锁定/解锁指令。

### 2.3 核心机制：USB 隧道连接

利用内嵌的 `adb` 工具，App 启动时自动执行 `adb reverse tcp:9527 tcp:9527`，在 USB 物理链路上建立 TCP 隧道。

* **优势**：延迟极低（<5ms），抗干扰能力强，无需关注 IP 地址配置，即插即用。

## 3. 系统要求

| 组件                 | 平台要求                         | 备注                                        |
| :------------------- | :------------------------------- | :------------------------------------------ |
| **macOS 端**   | macOS 11.0 (Big Sur) 或更高版本  | 支持 Apple Silicon (M1/M2/M3) 及 Intel 芯片 |
| **Android 端** | Android 10.0 (API 29) 或更高版本 | 需开启 USB 调试                             |
| **连接方式**   | USB 数据线                       | 自 v0.1.1 起，仅支持 USB 连接               |

## 4. 安装与配置

### 4.1 macOS 端安装

1. 解压下载的压缩包，将 `TouchPad.app` 拖入“应用程序”文件夹。
2. 首次运行时，若提示“无法验证开发者”，请在 `系统设置` -> `隐私与安全性` 中点击“仍要打开”。
3. **权限配置 (关键)**:
   * 应用启动后，系统会弹出请求“辅助功能”权限的弹窗。
   * **必须开启**此权限，否则应用无法控制鼠标光标。
   * *注：应用已内置 ADB 工具，无需单独安装 Android Platform Tools。*

### 4.2 Android 端安装

1. 将 APK 文件传输至平板并安装。
2. 安装完成后，建议在系统设置中授予应用“显示在其他应用上层”权限，以确保锁定模式的沉浸式体验。

## 5. 使用指南

### 5.1 连接设备 (USB 有线连接)

**本版本仅支持 USB 连接，以确保绘图零延迟。**

1. 使用数据线连接平板与 Mac。
2. 在平板上开启 **开发者选项** 和 **USB 调试**。
3. Mac 端应用会自动检测设备并建立连接。
   * *注意：首次连接需在平板端确认“允许 USB 调试”。*
4. 连接成功后，Mac 端菜单栏图标会显示设备名称。

### 5.2 功能操作

* **输入模式切换**:
  * 点击 Mac 状态栏图标 -> `输入模式`。
  * `仅接收触控笔`: 忽略手指触摸，仅响应触控笔，适合绘图。
  * `触控笔 + 手指`: 所有触摸均生效，适合作为触控板。
* **锁定屏幕**:
  * 点击 Mac 状态栏图标 -> `锁定移动设备界面`。
  * 平板将进入沉浸式绘图模式，屏蔽状态栏和导航栏。
  * 点击 `解除锁定` 恢复正常。

## 6. 可选功能：强力锁定

默认情况下，Android 系统允许用户通过上滑手势退出屏幕固定。若您需要**彻底屏蔽**退出手势（防止误操作），请执行以下步骤：

1. 确保 USB 连接已建立。
2. 在 Mac 上打开终端，执行以下命令授权：
   ```bash
   adb shell dpm set-device-owner com.example.touchpad/.MyDeviceAdminReceiver
   ```
3. 当提示 "Success: set active admin" 时，表示授权成功。
4. 此后点击“锁定”，应用将进入强力锁定模式，无法通过手势退出，只能通过 Mac 端解锁。

---

## 7. 卸载流程

### 7.1 macOS 端

* 直接将 `TouchPad.app` 从“应用程序”文件夹拖入废纸篓。
* 系统偏好设置中的“辅助功能”权限项会随卸载自动失效，无需手动清理。

### 7.2 Android 端

* 长按应用图标 -> 卸载。
* **重要**: 如果您之前开启了“强力锁定”模式，请**先执行**以下命令解除权限，否则可能无法卸载：
  ```bash
  adb shell dpm remove-active-admin com.example.touchpad/.MyDeviceAdminReceiver
  ```
  然后再进行卸载。
